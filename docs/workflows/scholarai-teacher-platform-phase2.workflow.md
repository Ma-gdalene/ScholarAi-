# ScholarAi Teacher Platform Workflow (Phase 2)

## Teacher Journey
1. Teacher logs in with Teacher ID.
2. Opens Create Assessment.
3. Selects Subject, Strand, Sub-strand, Year Group, Difficulty.
4. AI generates question set.
5. Teacher edits/deletes/adds items.
6. Teacher publishes quiz.
7. Students receive assessment in Learning Hub.

## Teacher Modules
- AI Assessment Generator
- Lesson Plan Generator
- Assignment Manager
- Attendance Tracker
- Announcement Center
