# ScholarAi Student Platform Workflow (Phase 1)

School: **Unique College International School**  
App: **ScholarAi**

## Core Journey
1. Student logs in with Student ID + Password.
2. Student lands on Dashboard.
3. Student opens Learning Hub.
4. Student starts quiz.
5. Secure Test Mode activates.
6. Student submits quiz.
7. Score and feedback appear in Grades & Feedback.

## Modules Included
- Learning Hub
- Assignments
- Tests & Quizzes
- Grades & Feedback
- Attendance
- Announcements

## Notes
- Secure mode in this prototype is browser-only demo behavior.
- Production should integrate MDM/kiosk lockdown policies at OS/device level.
